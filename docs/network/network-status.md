## Report: 22 October 2026

- **Komms is Bittensor mainnet subnet 27.** That is the subnet linked from [taostats.io/subnets/27](https://taostats.io/subnets/27). It recruits, checks and pays the operators who run Komms.
- **The app is not in public beta yet.** It runs on the Kaspa test network (Testnet 10). The launch version switches on with a planned reset of that test network, followed by the public beta. The public beta launches on Kaspa mainnet once the network features Komms relies on are active there.
- **Plans are not on sale yet.** Web billing is being built. Prices are on [Plans and pricing](../getting-started/plans-and-pricing.md).
- **Scoring has been run on the Bittensor test network** (netuid 503), with one team-run validator. Launch on subnet 27 requires three independent miners and a second, independently run validator. Until then, this page does not claim that Komms operators are earning mainnet emissions.
- **Miner onboarding** is opening to a small first group, who will test the full set-up before the guide is published. See [Mining on Komms](../mining-and-validating/mining.md).
