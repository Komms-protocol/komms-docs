# Security

If you find a security problem in Komms (the app, the network or komms.app), please report it privately.

**Email [info@komms.app](mailto:info@komms.app)** with "Security" in the subject line. Please include what you found, how to reproduce it, and what you think the impact is.

Please don't open a public issue or pull request for a security problem, and give us a reasonable time to fix it before sharing it elsewhere.

For mistakes in the documentation itself, a normal issue is fine.
